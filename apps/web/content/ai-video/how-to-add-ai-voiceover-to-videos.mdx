Here's a simple example of how you might use ElevenLabs' API to generate a voiceover:

```python
import requests

api_key = 'your_api_key_here'
url = 'https://api.elevenlabs.io/v1/generate'

payload = {
    'text': 'Hello, this is a sample voiceover.',
    'voice': 'en_us_male'
}

headers = {
    'Authorization': f'Bearer {api_key}',
    'Content-Type': 'application/json'
}

response = requests.post(url, json=payload, headers=headers)

if response.status_code == 200:
    with open('output.wav', 'wb') as f:
        f.write(response.content)
    print("Voiceover generated successfully.")
else:
    print("Error generating voiceover:", response.status_code)
```

This snippet demonstrates how to send a text to ElevenLabs' API and receive a voiceover file in return.
