# Getting Started with GitHub Copilot

Learning how to use GitHub Copilot transforms your development workflow by providing real-time AI-powered code suggestions directly in your editor. Whether you're a beginner or an experienced developer, Copilot streamlines repetitive coding tasks and accelerates project completion. With over 4.7 million paid subscribers as of January 2026—a 75% year-over-year increase—GitHub Copilot has become the industry standard for AI-assisted development. ## Creating a GitHub Account

Start by creating a GitHub account if you don't already have one. Visit [github.com](https://github.com) and sign up with your email. Verify your account through the confirmation email. An eligible free account qualifies for Copilot Free, which includes access to core features without requiring a paid subscription.

## Installing GitHub Copilot in VS Code

Follow these steps to set up Copilot in Visual Studio Code:

1. Open VS Code and navigate to the Extensions Marketplace (Ctrl+Shift+X / Cmd+Shift+X).
2. Search for "GitHub Copilot" and click **Install** on the official extension by GitHub.
3. Reload VS Code after installation completes.
4. Authenticate by clicking the Copilot status-bar icon and selecting **Sign in with GitHub**.
5. Complete the browser-based authorization flow.

## Enabling AI Features

Once authenticated, AI features activate automatically. Select **"Use AI Features"** from the Copilot status-bar icon to confirm enablement. For Copilot Free users, core completions are included at no cost. Copilot Pro subscriptions cost **$20/month** and unlock advanced features including Claude 3.5 Sonnet access and extended context windows.

### Using Copilot in Practice

Start typing code in any supported file:

```python
def calculate_fibonacci(n):
    # Copilot suggests the full implementation
    if n <= 1:
        return n
    return calculate_fibonacci(n-1) + calculate_fibonacci(n-2)
```

Press **Tab** to accept inline suggestions or **Escape** to dismiss them. Open Copilot Chat with **Ctrl+Alt+I** (Windows/Linux) or **Control+Command+I** (macOS) to ask contextual questions about your code, debug issues, or request refactoring advice.

In supported IDEs, Agent mode allows Copilot to propose multi-file edits and execute terminal commands with your approval—accelerating complex workflows.

# Using GitHub Copilot for Code Suggestions

## Typing Code to Receive Suggestions

Getting started with GitHub Copilot in VS Code takes just a few steps:

1. Open VS Code and locate the Copilot status-bar icon in the bottom right
2. Select **"Use AI Features"** from the dropdown menu
3. Sign in with your GitHub account
4. Enroll in **Copilot Free** if your account is eligible (no paid plan required)

Once authenticated, Copilot begins analyzing your code context immediately. As you type variable names, function signatures, or comments describing your intent, the AI generates contextual suggestions that match your coding style and project patterns. Suggestions appear as gray inline text within your editor—no popup dialogs or modal windows interrupting your flow.

## Accepting Inline Suggestions

When a suggestion appears, you have full control over acceptance:

- **Press Tab** to accept the entire suggestion
- **Press Alt+]** to cycle through alternative suggestions
- **Press Escape** to dismiss the suggestion and continue typing
- **Click directly on the suggestion** to accept partial text

This lightweight interaction model means you stay focused on your code logic rather than managing UI elements. For developers working with [Python]({{LINK_PYTHON}}) or [JavaScript]({{LINK_JAVASCRIPT}}), Copilot's language support is production-ready with extensive training data.

## Using Chat for Code Queries

For more complex problems, open **Copilot Chat** using:

- **Windows/Linux:** Ctrl+Alt+I
- **macOS:** Control+Command+I

Chat mode lets you ask Copilot questions like "How do I handle async errors in this function?" or "Refactor this loop for readability." The assistant provides explanations alongside code examples, making it ideal for learning unfamiliar patterns or debugging tricky logic.

In supported IDEs, **Agent mode** elevates collaboration further by proposing edits across multiple files and executing terminal commands—all with your approval before changes apply. This prevents accidental overwrites while maintaining developer agency.

**Pricing:** Copilot Free is available to all eligible GitHub users. Paid plans start at $10/month per individual or $19/month bundled with GitHub Pro.

## Tips for Effective Code Suggestions

**Start with clear context.** GitHub Copilot generates better suggestions when you provide meaningful variable names, function signatures, and comments. Instead of:

```python
def f(x):
    # TODO
```

Write:

```python
def calculate_monthly_interest(principal_amount, annual_rate):
    """Calculate compound interest for one month."""
```

Copilot now understands your intent and generates precise calculations rather than placeholder code.

**Use Chat effectively.** Open Chat with `Ctrl+Alt+I` (Windows/Linux) or `Control+Command+I` (macOS) to ask contextual questions about your codebase. Ask Copilot to explain complex functions, suggest refactoring strategies, or debug errors—this often works better than accepting inline suggestions for complex tasks.

**Leverage Agent mode** (available in supported IDEs) to let Copilot propose multi-file edits and run commands with your approval, accelerating larger refactoring operations.

## Common Pitfalls to Avoid

Don't blindly accept suggestions without review. Copilot sometimes generates syntactically correct but logically incorrect code—always verify security-sensitive operations, database queries, and API integrations.

Avoid relying on Copilot for architectural decisions. Use it for implementation details, not system design.
